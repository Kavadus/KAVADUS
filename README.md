# Web de Cuna Guardería KAVADUS

Diseño elegido: opción 1 (moderna y familiar). Sitio estático HTML/CSS/JavaScript, listo para GitHub Pages. No requiere servidores ni servicios de pago. Marca y contenido independientes de otros proyectos.

## Publicar gratis en GitHub Pages
1. Crea una cuenta en https://github.com/ (si aún no tienes una).
2. En GitHub: **New repository**. Escribe `kavadus-web`, selecciona **Public** y crea el repositorio.
3. En **Add file → Upload files**, sube **el contenido de la carpeta `kavadus-web`**, no el ZIP: `index.html`, `styles.css`, `script.js`, `README.md` y la carpeta `assets` completa. Confirma con **Commit changes**.
4. En el repositorio abre **Settings → Pages**, en **Build and deployment** selecciona **Deploy from a branch**, luego `main` y carpeta `/(root)`, y guarda.
5. Cuando termine de publicarse, el enlace será normalmente `https://TU-USUARIO.github.io/kavadus-web/`. Comprueba el enlace que muestre la pantalla Pages.

Antes de publicar, confirma que el titular de la guardería tiene autorización válida de madres, padres o tutores para usar públicamente estas imágenes en una página web. Si no la tiene, reemplaza o retira las fotos donde aparezcan menores; subirlas a un repositorio público también significa hacerlas accesibles a terceros. El repositorio contiene material gráfico aportado por el solicitante; no implica cesión de derechos.
